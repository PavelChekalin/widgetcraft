# Виджет+ (WidgetPlus)

Конструктор виджетов для рабочего стола Android: сетка кнопок, которую человек собирает сам —
приложения, ссылки, broadcast-команды, иконки из встроенной коллекции, цвет и оформление.

- Пакет: `com.pavel.widgetplus`
- Kotlin, minSdk 26, targetSdk 34, compileSdk 34, AGP 8.2.2, Gradle 8.2
- Без интернета, без рекламы, все настройки — в `filesDir/widgets.json`

## Что уже работает

- **Виджет** на рабочем столе 5×2 (в клетках лаунчера), растягивается; внутри своя сетка
  колонок×рядов (2–8 × 1–10).
- **Ячейка** — приложение (родная иконка), ссылка (открывается браузером) или команда-broadcast
  (например, кнопка VPN v2rayTun без открытия приложения).
- **Коллекция 293 иконок** Lucide (MIT) с поиском по-русски, категориями, 16 цветами и
  подложкой (круг / скруглённая / квадрат).
- **Оформление**: прозрачный/тёмный/светлый фон, скругление, плотность, подписи и их размер.
- **Несколько виджетов** с независимыми настройками, копия виджета, удаление конфига вместе
  с виджетом.
- **Готовые наборы**: VPN, Связь, Склад, Файлы.
- **Резервная копия** всех настроек в JSON-файл и восстановление (системный выбор файла).

## Сборка и установка

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat assembleDebug
adb -s <устройство> install -r app\build\outputs\apk\debug\app-debug.apk
```

Готовый debug-APK также лежит в `dist/WidgetPlus-0.1.0-debug.apk`.

## Инструменты разработки

- `tools/build_icons.py` — скачивает иконки Lucide из npm-пакета `lucide-static`, конвертирует
  SVG в vector drawable, нормализует pathData под Android и собирает `assets/icons.json`.
  Запуск: `python tools/build_icons.py` (нужен интернет только при первом скачивании,
  дальше работает кэш `tools/svg_cache`).
- `tools/make_grid_layout.py` — генерирует `res/layout/widget_grid.xml` (фиксированная сетка 8×10,
  RemoteViews не умеет добавлять вьюхи в рантайме).
- `tools/ui.ps1` — управление телефоном через uiautomator: находит кнопки по тексту или
  resource-id и нажимает их. Слепые тапы по координатам после установки уезжают.

## Особенности Android, из-за которых код выглядит именно так

- `targetCellWidth/targetCellHeight` в `appwidget-provider` **не задаются**: лаунчер Realme
  при их наличии раздувает высоту виджета до 3 клеток.
- В RemoteViews нельзя динамически добавлять вьюхи, а `GridLayout` доступен только с API 31 —
  поэтому разметка фиксированная 8 колонок × 10 рядов, лишнее скрывается.
- Иконки передаются только Bitmap, лимит транзакции Binder ~1 МБ — размер иконки уменьшается
  при большом числе кнопок (96/64/48 px).
- Lucide пишет дуги компактно (`a2 2 0 016 0`), Android такое не разбирает — конвертер
  нормализует путь, иначе приложение падает при инфляции drawable.

## Проверено на устройствах

- RMX2170 (Android 12): все функции первой версии, перезагрузка, сетка 5×6, страницы, наборы, копия, резервная копия.
- RMX3636 (Android 14): установка, виджет 5×2, набор «Рабочий», кнопка VPN — команда дошла до v2rayTun, VPN включился, индикатор стал зелёным.
- Эмулятор Android 16: отрисовка переключателя и набор «Рабочий», отладка падений.

## Проверка на телефоне

- Добавление: долгое нажатие на рабочем столе → Виджеты → Виджет+ → перетащить карточку.
  Простой тап по карточке в этом лаунчере не работает.
- Настройка открывается сама после перетаскивания; «Назад» отменяет добавление.
- Нажатия проверяются по журналу: `adb logcat -s WidgetPlus` (строка `cell click slot=...`).
